# Patch Notes

v2.0.0
- Joined Text, Label Format and Separator into one Overlay Widget Section.
- Added a preview of the overlay in the settings.
- Added a way to recover legacy format and backups.
- Fixed custom fonts for RimWorld 1.7.
- Fixed possible NullReferenceException(s) for formats.
- Added <if=content>text</if> rich text tag (see in the mod).
- Added comparation operations for formats and values (useful for 'if' tag).
- Added Silent Format Error (if enabled, when a token format has error will just return an empty string, instead of showing the token).
- Added 12-hour meridiem format token.
