Adds a customizable header overlay that displays at the start of the day.

[h1]HOW IT WORKS[/h1]
Every day*, in a certain hour of the game*, it will show an overlay* that contains Texts* and Separators*, for a certain duration*, and will start a sound*.

* Configurable in settings.

[h1]SETTINGS[/h1]
To configure the mod, go to: Options > Mod options > "Dawn of a New Day".
Everything you can think of can be configured, and if it isn't[spoiler], just ask me to implement it ;)[/spoiler]

[b]If you want to integrate a translation for the mod, follow these steps:[/b]
[olist]
[*]Go into the GitHub repository ([url=https://github.com/AlenDio0/DawnOfANewDay]DawnOfANewDay[/url])
[*]Clone the repository in your device.
[*]Look for "Languages" folder.
[*]Copy the path from "English" and rename it into your language.
[*]Go into "<YourLanguage>\Keyed" and translate the files in the chosen language.
[*]Finally, commit your changes and create a [b]Pull Request[/b] into the main branch of the repository.
[/olist]
